# Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, experience, and personal projects. It also includes an About Me section and a contact form.
[ErinBallinger.com](https://erinballinger.com/)

## Features

- **Personal Projects**: Display of my personal and professional projects with descriptions and links to GitHub repositories.
- **About Me**: A brief introduction to who I am, my background, and my professional journey.
- **Contact Form**: A form to get in touch with me, featuring fields for name, email, and message, with a confirmation on submission.

## Technologies Used

- **HTML**: For the structure and content of the site.
- **CSS**: For styling the website and making it responsive across devices.
- **JavaScript / JQuery**: For form validation and interactivity.
- **Node.js**: Backend server for handling form submissions (if applicable).
- **Cloudflare**: Hosting the website (or any other platform you use).
